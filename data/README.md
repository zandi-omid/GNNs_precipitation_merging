# Data

Large inputs and generated artifacts are not stored in Git. The public data
bundle will contain the processed gauge tables, graph artifact, sequence
metadata, and checksums needed to reproduce the experiments.

Expected source products are GHCN daily precipitation, IMERG V07, ERA5 daily
precipitation, and a 0.1-degree DEM. Reference-only evaluation products include
PRISM, MSWEP, MRMS, and GMCP.

The forthcoming download URL and SHA-256 manifest will be added here before the
paper release is tagged.
